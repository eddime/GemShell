# GemShell

Package HTML5 games as native desktop apps for Windows, macOS and Linux.

This repository holds the **releases only** — download GemShell from the
[Releases](https://github.com/eddime/gemshell/releases/latest) page.
Documentation: [gemshell.dev](https://gemshell.dev/guide/getting-started.html)

| System | Download |
|---|---|
| Windows | `GemShell-<version>-windows-x86_64.msi` |
| macOS (Apple Silicon) | `GemShell-<version>-macos-arm64.dmg` |
| macOS (Intel) | `GemShell-<version>-macos-x86_64.dmg` |
| Linux (Debian/Ubuntu) | `gemshell_<version>_amd64.deb` / `_arm64.deb` |
| Linux (any) | `GemShell-<version>-linux-x86_64.AppImage` / `-linux-arm64.AppImage` |

The builds are not code-signed. On macOS, open the app the first time with
right-click → Open.
